What it handles

This is a CDN rewrite tool, not a general-purpose website proxy.

  • github.com/.../blob/... → cdn.jsdelivr.net/gh/...
  • raw.githubusercontent.com/... → cdn.jsdelivr.net/gh/...
  • Useful for JS, CSS, images, JSON, WASM, and other static assets
  • Does not proxy arbitrary websites or bypass site restrictions
